# My taste

The rules I confirmed after seeing real work. Claude reads this before writing or editing
anything, and these rules beat every default in the kit.

**How a rule gets here:** I react to something real ("this hook is too slow", "love that
transition"), the `taste-learn` skill turns it into a clear rule and stages it in
`rules/PENDING.md`, and it only moves here after I say yes. Nothing gets in by guessing.

**How a rule leaves:** when a new rule replaces an old one, the old one is deleted, not marked
"outdated". This file only ever says what is true now.

Format: one rule per heading. The rule, then why, then how to apply it.

---

## My speaking pace
**Rule:** `<WPM>` words per minute (until measured, scripts assume 170).
**Why:** script length is computed from it, not guessed.
**How to apply:** after your first recorded take, Claude measures it (words in the transcript divided by minutes) and updates this line.

## Example: hooks land in the first second
**Rule:** the first spoken line states the payoff or the problem. No "hey guys", no intro.
**Why:** people decide to stay or swipe in about a second.
**How to apply:** if line one could be cut and the reel still makes sense, cut it.
