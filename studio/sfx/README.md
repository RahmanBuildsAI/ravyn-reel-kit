# sfx

Your sound effects. ravyn lists this folder in its Media drawer, and the four quick-sound
buttons in the Sound drawer drop these files at the playhead:

| File | Use it for |
|---|---|
| `click.wav` | small transitions, list items landing, UI taps |
| `tick.wav` | fine ticks: typing, counters, rows appearing |
| `slide.wav` | a card or the window moving into place |
| `paper.wav` | a highlight sweep on a screenshot, any paper or card reveal |

These four were made from scratch for this kit (synthesised with ffmpeg), so they are yours to
use anywhere. Replace any of them with your own sound of the same name and the buttons use yours.

**One sound per visual event, never on every word.** If one sound repeats more than about 8
times in a reel, rotate in a second version so it does not get stale.

For more sounds, see `docs/SFX.md` for free libraries whose licences let you use them in videos.
