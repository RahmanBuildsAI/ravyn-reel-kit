# fonts

Every font here comes from Google Fonts and is licensed under the **SIL Open Font License 1.1**:
free to use in your videos (commercial too), free to share with this kit. The full licence for
each family, with its copyright line, is in `licenses/`.

ravyn knows every file in this folder (`ravyn/lib/fonts.mjs`). To add a font, drop the `.woff2`
here and add one line to that list.
